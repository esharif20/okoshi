- `tools/cv` writes `public/cv.pdf` from the private CV with the phone number removed; a test extracts the PDF's text and fails if the number, or any run of 10 or more digits, is present.

- Each page has a title, description and preview image made from the Plate.
- Every found picture is credited in the Postcard footer with creator, source and licence.
