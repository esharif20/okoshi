# GH-9: The land, the Pagoda, Day and Night

Milestone: M2 The Diorama and the Stationery

The world around the House.

## Done when

- A plain, mist and a mountain range are painted behind the House; the table of the first Beat gives way to them in the Paint Beat.
- A five-storey Pagoda stands behind the House; each storey is a Layer and can be lit on its own.
- Day and Night are two sets of colours that cross-fade; the default follows the current time in London, and a toggle overrides it.
- At Night the House's screens glow from inside.

## Check

```
npm run build
```
